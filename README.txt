NoWaste - clickable app prototype (HTML + CSS + JavaScript, one file)

HOW TO RUN
1. Unzip the folder.
2. Double-click index.html. It opens in your browser. No installation or internet needed.
   (Optional, local server: open a terminal in this folder and run: python -m http.server 8000
   then open http://localhost:8000)

HOW TO SHARE A LINK (localhost links work only on your own computer)
- GitHub Pages: create a repository, upload index.html, then Settings > Pages > deploy from the main branch.
- Netlify Drop: go to app.netlify.com/drop and drag this folder into the page. You get a link.
- Or just send index.html as a file (rename it, for example, to NoWaste_App.html).

NOTES
- All prices, places and numbers are made up for the demo.
- The app saves your actions in the browser (localStorage). Use Profile > Reset demo to start again.
